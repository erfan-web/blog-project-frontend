# Blog Mini Project - Frontend

Frontend of a modern blog platform built with **Next.js 16, React js, TypeScript, TailwindCSS, and shadcn/ui**, consuming a custom-developed backend API.

---

## 🚀 Tech Stack

### Frontend Framework

- **Next.js 16**
- **React 19**
- **TypeScript**

### UI & Styling

- **TailwindCSS v4**
- **shadcn/ui (Radix UI)**
- **lucide-react icons**
- **next-themes (dark/light mode)**

### Forms & Validation

- **react-hook-form**
- **zod**
- **@hookform/resolvers**

---

## Backend API

This frontend consumes a **custom-developed backend API** built with Node.js, Express.js, Prisma, and MySQL.

### Backend Repository

👉 https://github.com/erfan-web/blog-project-backend

## 🛠️ Scripts

```bash
npm run dev      # Start development server
npm run build    # Build production bundle
npm run start    # Start production server
```

## ⚙️ Local Development Setup

### 1. Clone Repository

```bash
git clone https://github.com/erfan-web/blog-project-frontend.git
cd blog-project-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
npm run dev
```

The server will run on:

```arduino
http://localhost:3000
```
